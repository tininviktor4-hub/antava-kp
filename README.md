# Паспорт сделки

Локальная веб-программа для заполнения заявки и формирования коммерческого предложения.

## Как открыть

Откройте `index.html` в браузере. Для постоянной работы удобнее запускать папку через локальный веб-сервер Codex.

## Что уже работает

- ввод номенклатуры из заявки и номенклатуры к поставке;
- количество, производитель, единица измерения, цена и срок поставки;
- автоматический расчёт суммы каждой позиции;
- итог без НДС, НДС и итог с НДС;
- вставка целых столбцов и диапазонов из Excel;
- сохранение расчёта в браузере;
- формирование чистого коммерческого предложения;
- печать и сохранение КП в PDF средствами браузера.

По умолчанию используется НДС 22%. Значение можно изменить в реквизитах предложения.
